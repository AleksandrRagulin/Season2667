# Season2627

Табло прогнозов на футбольные матчи для четырёх участников — вкладки
«Лиги» и «Еврокубки», баллы считаются автоматически, матчи добавляются
вручную прямо на странице.

## Запуск

Открыть `index.html` в браузере, либо опубликовать папку через
GitHub Pages (Settings → Pages → Deploy from branch → `main` / `/`).

## Общая синхронизация между участниками

Без дополнительной настройки прогнозы сохраняются только в браузере
того, кто их вводит (localStorage) — на другом устройстве их не видно.

Чтобы все четверо видели одни и те же данные, нужно один раз
подключить бесплатный Firebase Realtime Database — подробная
пошаговая инструкция прямо в файле [`firebase-config.js`](firebase-config.js).
Пока значения в нём не заполнены настоящими, сайт работает в локальном
режиме (в шапке общего зачёта видно, какой режим сейчас активен).
